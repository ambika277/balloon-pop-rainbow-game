# 🎈 Balloon Pop: Rainbow Challenge

**A colourful and interactive balloon popping game developed as a Multimedia Systems Project.**

## 📌 Project Description

Balloon Pop: Rainbow Challenge is an entertaining arcade-style game in which players pop colourful balloons to earn points before the timer runs out.

The game features bright neon-coloured balloons, white outlines, sound effects, animated clouds, bonus balloons, and bomb balloons. Players must achieve the highest possible score while managing their lives and time.

## ✨ Features

- 🎈 Colourful neon balloons with white outlines.
- ⭐ Bonus balloons that provide extra points.
- 💣 Bomb balloons that reduce player lives.
- 🎵 Sound effects for popping balloons and special events.
- ☁️ Animated clouds and attractive backgrounds.
- ⏱️ 60-second gameplay timer.
- ❤️ Five lives for each game.
- 🏆 Score tracking system.
- ⏸️ Pause and resume functionality.
- 🔄 Restart option after game over.
- 📱 Responsive mobile browser support.
- 🖱️ Mouse and touchscreen controls.

## 🎮 Game Rules

1. Pop normal balloons to earn 10 points.
2. Pop a bonus balloon to earn 25 points and activate double scoring for 5 seconds.
3. Pop a bomb balloon and lose one life.
4. Missing a balloon does not reduce your lives.
5. Complete the game before the 60-second timer reaches zero.
6. Try to achieve the highest score possible!

## 🚀 How to Run the Game

### Option 1: Play in a Web Browser

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The game will open in your browser.
5. Click or tap Start Game to play.

No Python installation is required for the browser version.

### Option 2: Run the Python/Pygame Version

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install Pygame:

```bash
pip install pygame
```

5. Run the game:

```bash
python main.py
```
